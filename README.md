# BloodLink Dashboard

A simple React + Vite prototype dashboard for the BloodLink blood-bank monitoring project.

## Run
```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Included demo interactions
- Simulate RFID scan: adds a dummy blood bag and assigns a slot.
- Search inventory.
- Navigation buttons for prototype sections.
- Rack status visualization.
- Temperature warning simulation.
- Notification / activity demo buttons.

The data is currently hard-coded in React state; Firebase/ESP32 integration can be added later.
